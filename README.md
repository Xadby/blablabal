# 🎵 Xadby Pad

Приложение для привязки звуков к горячим клавишам с выводом в виртуальный микрофон и встроенной библиотекой.

## 🚀 Для пользователей (Как начать)

Вам **НЕ НУЖНО** устанавливать Python или что-либо настраивать!

1. Скачайте архив `XadbyPad_Windows.zip` из раздела Releases.
2. Распакуйте архив в любую папку.
3. Запустите `XadbyPad.exe`.
4. Готово! Добавляйте звуки и назначайте клавиши.

> **💡 Совет для стримеров и геймеров:**  
> Чтобы друзья слышали звуки в Discord, установите [VB-Audio Virtual Cable](https://vb-audio.com/Cable/).  
> В настройках Xadby Pad выберите: **Вывод** → Ваши наушники, **Дублировать в** → `CABLE Input`.  
> В Discord выберите `CABLE Output` как микрофон.
